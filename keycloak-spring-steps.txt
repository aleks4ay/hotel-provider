1. Run keycloak:
    docker run --name keycloak-hotel-provider -e KEYCLOAK_ADMIN=admin -e KEYCLOAK_ADMIN_PASSWORD=admin -p 18080:8080 quay.io/keycloak/keycloak:23.0.6 start-dev

2. Запустить localhost:18080
	2.1 Зайти в Админ-консоль, admin/admin
	2.2 Создать новое пространство (нажать на master --> create realm --> ввести только `Realm name` = hotel-provider, например)

3. Создать клиента. Clients --> Create Client
	-1 General settings:
		Client type: OpenID Connect
		ClientID: {spring-app}
		Name: {Spring Boot Admin Client}
		Always display in UI: Off
		--> next
	-2 Capability config:
        Client authentication: ON (client становится confidential)
        Authorization: OFF
        Authentication flow: выбрать
            Service accounts roles	ON
            Direct access grants OFF (пользователи не логинятся через этот client)
		--> next
	-3 Login settings:
		--> Save
4. Скопировать секрет Clients → spring-app → Credentials (8UwMrcdNc8o9IsrZu51dDDXwJJTxy6KD)
5. Добавить роль Clients → spring-app → Service account roles
    - клацнуть по "Assign role"
    - переключиться с "Filter by realm-role" на "Filter by clients"
    - выбрать роли:
        - manage-users (экран 2 в списке)
        - view-users (экран 3 в списке)
        - view-realm (для назначения ролей)
        - query-users (желательно)
      --> Assign

6. Для получения Bearer-токена нужно
curl -X POST \
  http://localhost:18080/realms/hotel-provider/protocol/openid-connect/token \
  -d grant_type=client_credentials \
  -d client_id=spring-app \
  -d client_secret=8UwMrcdNc8o9IsrZu51dDDXwJJTxy6KD

7. Скопировать конфигурацию себе на комп (потом переместить в папку проекта ./config/keycloak)
    7.1 Создать файл-конфиг внутри контейнера (keycloak-sandbox - это имя контейнера):
        docker exec keycloak-sandbox /opt/keycloak/bin/kc.sh export --dir /opt/keycloak/data/export --realm sandbox --users realm_file   - работает
    7.2 скопировать на комп (в папку юзера):
        docker cp keycloak-sandbox:/opt/keycloak/data/export/sandbox-realm.json ./sandbox-realm.json
